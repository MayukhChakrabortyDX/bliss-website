# CLI Utilities & Native Systems in Bliss

Command-line tools live or die by startup time and distribution simplicity. Nobody wants to install a runtime manager just to run a file processor, build helper, or system utility.

## Instant startup, zero dependencies

Because Bliss compiles to native machine code without a virtual machine or interpreter warmup, CLI tools start in milliseconds and run predictably even on large inputs.

## Built for cross-platform distribution

Bliss targets the platforms developers actually ship to—**Linux** (`x86_64` and `ARM64`), **Windows** (`x86_64` and `ARM64`), and **macOS** (Apple Silicon)—with a single-binary workflow modeled by the `bliss` CLI itself.

## Predictable error handling and diagnostics

From file I/O to structured output, Bliss emphasizes clear, explicit control flow and exact diagnostics—making it straightforward to build developer-friendly CLIs that fail cleanly and plug into scripts or CI pipelines.
